## 1️⃣ 安装

```bash
# 克隆/进入项目目录
cd TalentLens-AI

# 安装依赖
pip3 install -r requirements.txt

# 或使用 Makefile
make install

# 验证安装
./resume-cli --version
```

**期望输出：**
```
resume-cli v0.1.0
```

## 2️⃣ 配置 API Key

### 方式一：.env 文件（推荐）

```bash
# 复制配置模板
cp .env.example .env

# 编辑 .env，填入你的 API Key
vi .env   # 或用任意编辑器
```

`.env` 内容示例：
```bash
OPENAI_API_KEY=sk-your-api-key-here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

### 方式二：环境变量

```bash
export OPENAI_API_KEY="sk-your-api-key-here"
export OPENAI_BASE_URL="https://api.openai.com/v1"
export OPENAI_MODEL="gpt-4o-mini"
```

### 验证配置

```bash
python3 -c "
from resume_cli.config import get_settings
s = get_settings()
print('API Key:', '✅ 已配置' if s.has_api_key else '❌ 未配置')
print('Model:', s.openai_model)
print('Base URL:', s.openai_base_url)
"
```

**期望输出：**
```
API Key: ✅ 已配置
Model: gpt-4o-mini
Base URL: https://api.openai.com/v1
```

| 测试场景 | 命令 | 期望结果 |

## 9️⃣ 常见问题

### Q: 提示 "未配置 OPENAI_API_KEY"

**A:** 确认 `.env` 文件在项目根目录，且包含有效的 `OPENAI_API_KEY=sk-...`

### Q: AI 调用超时

**A:** 在 `.env` 中增加超时时间：
```bash
REQUEST_TIMEOUT=120
```

### Q: 使用第三方 API（DeepSeek、通义千问等）

**A:** 修改 `.env` 中的 `OPENAI_BASE_URL` 和 `OPENAI_MODEL`：
```bash
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

### Q: Python 版本问题

**A:** 确保使用 Python 3.9+：
```bash
python3 --version  # 应 >= 3.9
```
